# DevHelp – Project Rules

- Do not change the UI unless explicitly requested.
- Do not change the visual design, colors, spacing, animations or layout unless explicitly requested.
- Do not add comments inside the code.
- Do not leave TODO comments.
- Do not leave unused imports, variables or dead code.
- Keep the code clean, readable and maintainable.
- Avoid over-engineering.
- Use meaningful names for variables, functions and files.
- Do not hardcode secrets or API keys.
- Use environment variables for external services.
- Preserve existing routes and behavior unless requested.
- Before modifying code, inspect the current architecture and reuse existing patterns.
